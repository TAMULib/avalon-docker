## Usage
1. Clone this Repo
   git clone https://github.com/TAMULib/avalon-docker/
   
   git checkout tamu_master
   
   git status
   
   
   On branch tamu_master

3. Copy dotenv.example to .env and fill in the relevant info.

5. From inside the avalon-docker directory
  * `docker-compose build`
  * `docker-compose up` to stand up the stack

To access the site, visit http://localhost:3000 in your browser.
